# Ray Tracer Project

## Overview
This project is a ray tracer implementation built from scratch.

## About the Project
Building a ray tracer from the ground up is no joke I almost had a sesuire. There were plenty of moments where I hit my keyboard and almost broke it trying to get the math right, optimize performanc, and debug rendering issues. But honestly, the experience was shit. having access to good documentation made a huge difference—it really helped me understand the concepts better and produce soemthing and I am soo thankfull I did a little game dev.

## Key learnings
- Understanding ray-object intersection calculations
- implementing lighting and reflectivity models
- Debugging visual artifacts
- Adding materials to it

## Results
You can check out some of the rendered images and results in the GitHub repo. Ive stored a few examples showing different scenes and features the tracer can do. the images are also in the release
