# Ray Tracer Project

## Summary
This project is a ray tracer implementation built from scratch.

## About the Project
Building this project made me realize that making anything with heavy math will take away your hair and sanity, will I was able to get my hands on some documentation about ray tracing really helped in my understanding and specaliy my game dev knowledge since ray tracing is the fundemantil thing in game engines if you wanna make this yourself and understand it go to medium docs about ray tracing or game makers ray tracing it helped me alot

## Key understandings
- Understanding ray-object intersection calculations
- implementing lighting and reflectivity models
- Debugging visual artifacts
- Adding materials to it

## Results
You can check out some of the rendered images and results in the GitHub repo. Ive stored a few examples showing different scenes and features the tracer can do. the images are also in the release
